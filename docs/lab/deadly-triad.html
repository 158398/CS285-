死亡三合一滑块

函数逼近 + bootstrap + off-policy 为什么能让 Q 值爆炸?拖动三个旋钮,亲眼看 Q 迭代的三种命运。 这是标量示意图(常数偏差 b 模拟 max 算子的系统性高估),机制与真网络一致—— 第 3 讲 CartPole lr=0.05 的现场就是它。

更新规则:移动靶 Q←Q+α(r+γbQ−Q);冻结靶 Q←Q+α(r+γbQ冻−Q),每 K 步 冻结值←当前 Q。 真值上限 Q* = r/(1−γ)(虚线);偏差不动点 r/(1−γb)(红线,γb<1 时存在)。

怎么玩

  1. 先把 b 拖到 1.00(无偏差):任意 α、γ 都收敛到 Q*——无偏差的世界很温柔。
  2. 把 b 拖到 1.05:γ=0.99 时 γb=1.0395>1,任何学习率都爆炸——偏差过了 1/γ 的红线,复利就赢了。这正是 CartPole lr=0.05 的遭遇。
  3. 保持 b=1.05,把 γ 降到 0.90:γb=0.945<1,又收敛了——但收敛到 r/(1−γb)≈18.2 而不是真值 10:偏差被 bootstrap 放大了 1/(1−γb) 倍。
  4. b=1.01 的"温和偏差":γ=0.99 时 γb=0.9999,不动点是真值的 100 倍——这就是 double Q 之后仍残留的高估。
  5. 关掉 target network(移动靶):收敛边界 α < 2/(1−γb);打开冻结靶,注意爆炸只是被放慢,没有被治——target network 治"晃"不治"歪"。
