Multistep Q-Learning:偏差、方差与重要性采样

本页是作业理论题(hw3.pdf §1 Multistep Q-Learning)的完整伴读:推导逐节对应题号 1.1–1.5, 公式编号与 PDF 一致。你将学会:max 算子为什么天生乐观、N-step 旋钮两端的得失、 函数逼近让哪些保证失效、以及 off-policy 修正为什么在 N=1 免费、N→∞ 致命。

§0 题目设定(与 PDF 一致)

N-step Q-learning 的靶子(PDF 式 1):

$$y_{j,t} \leftarrow \sum_{t'=t}^{t+N-1} \gamma^{t'-t} r_{j,t'} \;+\; \gamma^{N} \max_{a_{j,t+N}} Q_{\phi_k}(s_{j,t+N}, a_{j,t+N})$$

回归拟合(式 2)与策略更新(式 3):

$$\phi_{k+1} \leftarrow \arg\min_{\phi \in \Phi} \sum_{j,t} \Big( y_{j,t} - Q_\phi(s_{j,t}, a_{j,t}) \Big)^2, \qquad \pi_{k+1}(a_t \mid s_t) = \mathbb{1}\big[ a_t = \arg\max_{a} Q_{\phi_{k+1}}(s_t, a) \big]$$
读法:j 是 buffer 里轨迹的索引,t 是轨迹内时刻。N=1 时连加只剩 r_{j,t},退化成你熟悉的 Q-learning 靶子;N→∞ 时 bootstrap 项消失,是 Monte Carlo。

算法 1 的循环:用 π_k 采 B 条新轨迹更新 buffer → 算靶子(式 1)→ 拟合(式 2)→ argmax 改进(式 3),重复 K 轮。 五个小题问的都是同一个东西的不同切面:这个靶子什么时候无偏、什么时候收敛、方差多大、函数逼近后还剩什么、off-policy 怎么修。

§1.1 TD-Learning Bias:B Q̂ 是 BQ 的无偏估计吗?

Jensen 不等式:f 凸 ⇒ E[f(X)] ≥ f(E[X])。max 对每个分量都是凸函数(一族线性函数的上确界)。

设 Q̂ 是对 Q 的无偏噪声估计(逐状态-动作)。Bellman backup 里装着 max:

$$\mathbb{E}\big[\max_{a'} \hat{Q}(s',a')\big] \;\ge\; \max_{a'} \mathbb{E}\big[\hat{Q}(s',a')\big] \;=\; \max_{a'} Q(s',a')$$

所以即使 Q̂ 逐点无偏,取 max 这个动作本身就把期望推高——答案是 No: $B\hat{Q} = r + \gamma \max_{a'} \hat{Q}(s',a')$ 不是 $BQ$ 的无偏估计。直觉:max 专挑"运气好的那次噪声"。 这是全作业偏差链的第一环(→ double Q 的动机)。

模拟验证(Seeing-Theory 式):真值全 0,10 个动作各加 N(0,1) 噪声,看 max 的分布。

§1.2 Tabular Learning:六个格子怎么判

三个命题:I. Qφk+1 是上一策略 Qπk 的无偏估计;II. 固定 B、k→∞ 时是 Q* 的无偏估计; III. k,B→∞ 时收敛到 Q*。逐格判据只有三个问题:

  1. 靶子里是 max 还是 π?——决定 I。靶子恒为 max(最优性算子),从来不是"按 π_k 采样"(评估算子), 所以 I 在六个格子全 False:它估计的是朝 Q* 的贝尔曼最优算子,不是 Q^{πk}。
  2. 固定 B 的极限是什么?——决定 II。固定数据反复拟合 = 在经验 MDP 上做价值迭代,不动点是经验 MDP 的 Q̂*; 有限样本 + max 使 E[Q̂*] 对 Q* 保持乐观偏差(§1.1 的同族)。II 在六个格子全 False。
  3. 收缩性 + 覆盖 + off-policy 修正——决定 III。表格下 backup 是 γ-收缩,覆盖假设满足:
III(收敛到 Q*)on-policyoff-policy
N = 1✅(Q-learning 经典收敛)✅(max 不在乎数据是谁采的)
N > 1✅(数据来自当前 πk,与靶子自洽)❌(多步奖励按 π′ 采,无修正 → 见 §1.5)
N → ∞✅(MC 评估 + 贪心改进 = 策略迭代)❌(需要全轨迹 IS,方差爆炸)
易错:N>1 on-policy 的靶子混着"πk 采的真奖励 + max bootstrap",k→∞ 时随策略改进自洽收敛; 一旦 off-policy,多步奖励的分布就错了——修正它的唯一办法是 §1.5 的似然比。
你该知道:III 的第一行(off-policy 也收敛)就是 replay buffer 合法性的理论出生证; 第二行告诉你这张出生证只覆盖 N=1。

§1.3 Variance of Q Estimate:哪种 N 方差最大/最小?

靶子的随机性有两个来源:真实奖励的采样噪声(随 N 累积)与 bootstrap 项的估计误差(不随 N 变,但有偏)。 N 越大,靶子越像 Monte Carlo——无偏但噪声大;N=1 把未来交给 Q̂——偏差换安静:

答案理由
方差最高N → ∞整段未来的奖励全部采样累积,无 bootstrap 降噪
方差最低N = 1只有一步真实奖励,未来全部由 Q̂ 垫付
与 HW2 的呼应:GAE 的 λ 是同一个旋钮在 advantage 侧的版本(λ=0 全 bootstrap,λ=1 全 MC)。 HW2 你拧在偏方差侧,HW3 拧到底(N=1)——两份作业因此一个讲方差、一个讲偏差。

§1.4 Function Approximation:哪些保证失效了

收缩性:表格 backup 满足 ‖BQ₁−BQ₂‖∞ ≤ γ‖Q₁−Q₂‖∞,Banach 不动点 ⇒ 收敛。 函数逼近的"拟合"是把 BQ 投影到函数类;投影在 L₂ 不扩张、在 ∞-范数可扩张,复合后不再保证收缩。

四个命题:① N=1 时是 Q^{πk} 无偏估计;② N=1、B,k→∞ 收敛到 Q*;③ N>1 收敛;④ N→∞ 收敛。 假设:对任意确定性 π,函数类能精确表达 Q^π。

  1. ① False:max 的偏差不因函数逼近消失,还多一层投影偏差。
  2. ② False:函数逼近 + bootstrap + off-policy = 死亡三合一,可能发散(连收敛都没有,更谈不上收敛到 Q*)。
  3. ③ False:同②,有限 N 都带 bootstrap。
  4. ④ True:N→∞ 时式 (2) 退化为对 on-policy MC 回报的回归;能精确表达 ⇒ 每轮得到精确 Q^{πk}, 整套算法退化为精确策略迭代,有限 MDP 上收敛到 Q*。
你该知道:④ 是这题最漂亮的一格——bootstrap 一拿掉,函数逼近就不再可怕; 它精确告诉你"偏差从哪来"。想亲手看这个发散,去 实验室的死亡三合一滑块 (函数逼近的发散版另有 concept_demos.py 的两状态反例,×1.08/步)。

§1.5 Multistep Importance Sampling:修正项怎么写

用 π′ 采的轨迹估计"对 π 改进"的 N-step 靶子,需要给未来每一项乘似然比 $\rho_s = \dfrac{\pi(a_s|s_s)}{\pi'(a_s|s_s)}$。 逐步推(点上一步/下一步):

$$\mathbb{E}_{\pi}\Big[ \sum_{t'=t}^{t+N-1} \gamma^{t'-t} r_{t'} + \gamma^N \max_a Q(s_{t+N},a) \,\Big|\, s_t, a_t \Big]$$
$$r_t + \mathbb{E}_{\pi}\Big[ \sum_{t'=t+1}^{t+N-1} \gamma^{t'-t} r_{t'} + \gamma^N \max_a Q(s_{t+N},a) \,\Big|\, s_t, a_t \Big]$$
$$r_t + \mathbb{E}_{\pi'}\Big[ \sum_{t'=t+1}^{t+N-1} \Big(\prod_{s=t+1}^{t'} \rho_s\Big) \gamma^{t'-t} r_{t'} + \Big(\prod_{s=t+1}^{t+N-1} \rho_s\Big) \gamma^N \max_a Q(s_{t+N},a) \,\Big]$$
$$y_{j,t} = r_{j,t} + \sum_{t'=t+1}^{t+N-1} \Big(\prod_{s=t+1}^{t'} \rho_{j,s}\Big) \gamma^{t'-t} r_{j,t'} + \Big(\prod_{s=t+1}^{t+N-1} \rho_{j,s}\Big) \gamma^N \max_a Q_{\phi_k}(s_{j,t+N}, a)$$
$$N{=}1:\; y_{j,t} = r_{j,t} + \gamma \max_a Q_{\phi_k}(s_{j,t+1},a) \quad(\text{无需修改})$$ $$N{\to}\infty:\; \text{权重} = \prod_{s=t+1}^{T} \frac{\pi(a_s|s_s)}{\pi'(a_s|s_s)} \;\Rightarrow\; \text{方差} \sim \text{随 horizon 指数爆炸}$$
主线收口:bootstrap 与 IS 是处理 off-policy 的两个端点——截断 horizon(偏差换安静) 或全程重加权(无偏换爆炸)。这就是为什么 DQN 敢用 buffer,而 HW2 的 PG 不敢。
你该知道:方差随 horizon 指数爆炸正是你在 HW2 §9.4 推过的结论; 理论题把两份作业在同一个公式里接上了。

自测(合上答案再想一遍)

§1.1 的偏差和 §1.2-II 的偏差是同一个机制吗?

同族不同身。§1.1 是"对无偏估计取 max"的 Jensen 偏差;§1.2-II 是"在固定有限数据集上求经验 MDP 最优解" 的乐观偏差(经验最优对真实最优的偏差)。两者方向一致(都偏高),bootstrap 会把它们一起复利。

III 中 N>1 off-policy 判 False,但 DQN 的 replay buffer 也是 off-policy,为什么不矛盾?

DQN 是 N=1(III 第一行:off-policy 也收敛)。buffer 里 N>1 的靶子才需要 §1.5 的 ρ 修正; 这也正是 Rainbow 等用 multi-step return 时要么调小 N、要么接受偏差的原因。

§1.4-④ 说"MC + 精确函数表达 = 策略迭代",这对实践有什么用?

它给出偏差的对角线:凡是引入 bootstrap 的设计(小 N、target 滞后、FA 投影)都在往偏差侧走; 凡是靠近 MC 侧的设计(大 N、GAE 大 λ)都在往方差侧走。调参的本质是在这条对角线上选位置。
