一个环境的三种死法:LunarLander

同一个登月器,我在三份作业(实际是四次)里,用三种完全不同的算法范式去着陆它: on-policy 策略梯度、off-policy vanilla DQN、double DQN。 三次三种结局,第四次最魔幻。这一个环境,就是整部教程误差观的缩影。

第一次相遇:HW2 策略梯度(方差的故事)

武器:REINFORCE + reward-to-go + baseline + GAE,λ 从 0 扫到 1。 结局:λ=0.99 摸到 180 达标线,λ→0(bootstrap 多)学不动,中间 λ 冲高后塌陷。

当时的隐藏剧情:同估计器、同种子,仅浮点求值顺序不同,两条 run 就分岔成 −42 和 148。 那是我第一次学到:LunarLander 是个混沌环境,单 seed 的定量结论不可信。

第二次相遇:HW3 vanilla DQN(偏差的故事,悲剧)

武器换成 off-policy 的 DQN: replay buffer + target network + ε-greedy。 结局:三个种子全军覆没(末段 −57/−52/−91),全程 max 只有 11–40。 其中 2 号种子曾单次摸到 222 分——然后彻底崩盘。

死因不是探索不够、不是网络太小,是 max 高估:取 max 时专挑运气好的噪声, Q 在某区域虚高 → 策略慕名而去 → 数据一到,虚高被证伪 → 崩盘。 vanilla 的 Q 预测(≈37)比 double Q(≈30)更高,回报却差一个量级——虚高的活捉现场。

行为证据(翻车博物馆展品):vanilla 训练 300k 后的三局连录——悬停、犹豫、栽下去。

第三次相遇:double DQN(偏差被按住之后)

只改一处:选动作用在线网络、评分用 target 网络("选"与"评"分家)。 结局:三个种子 89/130/59,最优单局 211–277,曲线在 300k 处仍陡峭爬升。

第四次相遇:重跑一遍,世界线又变了(混沌的故事)

为了拍视频,用同样的代码、同样的种子重跑 double DQN。结局:

run末段均值最优单局判读
HW3 原 seed 1/2/389 / 130 / 59216 / 211 / 142正向爬升
重跑 seed 1−5310几乎没学会
重跑 seed 2−91222双峰:偶尔神勇,多数坠毁

同种子结果都不同(CPU 线程调度改变浮点求和顺序 → 微小差异被混沌放大)—— HW2 发现的"混沌分岔"在 HW3 原样重演。最后的视频是从 15 局里筛出的 2 局软着陆:

double DQN 最佳单局(186/167)

15 局只有 2 局能软着陆——这就是"最优单局 211–277、均值 59–130"的行为级样子

一个环境教我的四件事

  1. 方差会杀人(HW2):不给 baseline/GAE,无偏估计器照样学不动——λ 旋钮能救一半。
  2. 偏差更会骗人(HW3 vanilla):Q 值虚高时,学习曲线会"看起来在进步"——然后崩盘。要看 Q 的绝对值,不只看回报。
  3. 选评分家是高估的解药(doubleQ):一处改动,从全负到正向爬升。
  4. 混沌环境只看均值会误事(四次重逢):LunarLander 必须多 seed、看单局分布(均值 59 和均值 −82 的 agent,最佳单局都是 220+)。 你写论文时报告"mean ± std over seeds",就是因为这种环境存在。
和教程主线的关系:三讲的误差观——分布偏移(HW1)、方差(HW2)、偏差(HW3)—— 在这一个环境里全部现身了一遍,外加第四条隐藏款:混沌。这也是为什么我把 LunarLander 叫"一个环境的三种死法": 它不是难,它是把每种失败都演示给你看。
