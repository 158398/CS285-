从模仿到自主:深度强化学习三讲实战

UC Berkeley CS285(Fall 2023)三份作业的完整复现与个人讲解。官方给你文档,这里给你工程落地和思维培养。

三份作业对应三大方法族:模仿学习(BC/DAgger)、策略梯度(REINFORCE/GAE)、价值学习(DQN/SAC)。 每学一族,我们都追问同一个问题——它什么时候会失败、为什么?于是这里还有一条贯穿始终的思维线: 用误差分析拆解每一次失败(分布偏移、方差、偏差、信息不足),用方差-偏差权衡理解每个技巧为什么有效。 所有结论,都配了自己跑出来的对照实验。

第 1 讲 · 分布偏移

向已经学会的专家学习

同样是模仿:在 Ant 上几乎满分,在 Hopper 上却直接崩盘——同一个算法, 换一副身体、换一个任务,命运天差地别。差别不在网络大小, 而在你模仿的数据分布罩不罩得住这副身体。 本章讲清这件事在数学上意味着什么(复合误差),以及工程上怎么用 DAgger 落地补救。

 第 2 讲 · 方差控制

亲手推导策略梯度,再驯服它的噪声

从 score function trick 推出 REINFORCE:期望精确,但方差能大到学不动。 reward-to-go、baseline、GAE 是一套方差控制工具,我们逐个上秤—— 哪件是底线、哪件是锦上添花,在四类环境里各见分晓。

 第 3 讲 · 偏差控制

从打分表里读出策略

从 Bellman 方程到 DQN 三件套与 double Q,再到连续动作的 SAC (熵正则、reparametrize、clipped-Q):bootstrap 用偏差换方差,而偏差会复利。 同一目标下的三组对照实验,把"晃"与"歪"分开治。
